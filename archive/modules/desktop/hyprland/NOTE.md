# Archived Hyprland desktop config with other components

It got archived because Hyprland changed their config syntax from simple text
to lua at around version 0.53 - 0.55 (can't remember which one exactly). This
change made this nix config obsolete, as their HM options got also updated
accordingly. As I wanted to try out niri and noctalia anyway (which I like
quite much), I didn't put the effort into fixing my Hyprland config. I keep
this module as archived though, for past reference, or if I want to update it
sometime in the future.
